HOW TO READ

指标怎么看

让第一次看到这些指标的人，也能立刻知道“高了好还是低了好”。

↓ 越低越好

适用于误差、长尾误差、CPU、RAM、跳变次数等指标。

↑ 越高越好

适用于重叠率、平面比例、平面特征强度等指标。

◎ 越接近目标越好

适用于“应接近完整 bag 时长”等目标型指标。

— 仅供参考

适用于点数、轨迹长度、首尾距离等不能简单判定高低优劣的指标。

HOW TO EXTEND

以后新增算法，不改网页代码

  1. 复制 experiments/_template.json，填入新算法指标。
  2. 把新视频放到 media/，在 JSON 里填写路径。
  3. 执行 python3 scripts/build_data.py。
  4. 刷新网页，新方案会自动出现在筛选、图表、表格和视频区。
